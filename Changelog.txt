l4t-r39.2.1 community port (2026-09-28)
==========================
    - Support for L4T-39.2.1 / Jetpack 7.2.1 on Jetson Orin (kernel 6.8)
        - camera-core changes from l4t-r38.4, fitted to 39.2.1
        - fr_* drivers and Orin overlays from l4t-r36.4.4
    - build-tested with OE4T meta-tegra; not yet tested on hardware
    - ISP files and build scripts unchanged from l4t-r36.4.4
    - hardware test 2026-09-28 (Orin Nano devkit Super, IMX900 over GMSL3):

        - Argus needs an IMX900 NITO file (Jetpack 7.2 rejects .isp)
        - V4L2 controls start at their minimum (1.5 fps) until set
      see TEST-RESULTS-l4t-r39.2.1.md
    - fr_imx900: controls start at their DT defaults (72 fps / 10 ms) instead of the minimum
